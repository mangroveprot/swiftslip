## Vercel deploy fix (STATIC_BUILD_NO_OUT_DIR)

- Cause: repo is an npm workspace; Vite root is `web/`, so the build outputs `web/dist`, but Vercel (Root Directory = repo root) looked for `./dist`.
- Added root `vercel.json`: `framework: vite`, `buildCommand: npm run build -w @swiftslip/web`, `outputDirectory: web/dist`, SPA rewrite `/(.*) -> /index.html`.
- Verified locally: `npm run build -w @swiftslip/web` → `web/dist/index.html` exists. `dist` is gitignored.
- Note: `web/public/_headers` is Cloudflare/Netlify format — Vercel ignores it, so security headers are not applied there.

## Vercel build hang: dev watcher loop

- Symptom: deploy log repeats `Using TypeScript 5.9.3 (local user-provided)` ~1/s, never finishes.
- Cause: that banner is `ts-node`; the host was running `npm run dev` (API `ts-node-dev --respawn`), which crash-loops forever. `tsup` (the real API build) does not print that line.
- Fix: added `api/scripts/guard-dev.mjs`; `api/package.json` dev = `node scripts/guard-dev.mjs && ts-node-dev ...`. Under `CI=1` it exits 1 with a clear message. Local dev unaffected.
- Added "Deploying to Vercel" note to README.
- Action for user: commit/push `vercel.json` (was untracked) + set Vercel Build Command to `npm run build -w @swiftslip/web`, Output `web/dist`, Root Directory repo root.
