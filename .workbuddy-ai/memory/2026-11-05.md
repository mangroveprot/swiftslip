## Diagnostic recipe worth reusing

- To inspect the live DB without leaking secrets: parse `api/.env` in a `node -e` one-liner,
  `fetch(SUPABASE_URL + "/rest/v1/<table>?select=...")` with `apikey` + `Bearer` service-role
  headers, print only non-secret columns. `activity_logs?action=eq.attachment.uploaded` gives
  exact upload timestamps to compare against `storage_settings.updated_at`.
- Filename convention is a reliable fingerprint of which code version served an upload.
